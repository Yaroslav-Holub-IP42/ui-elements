UI елементи

1. Radiobutton (перемикач)

Дозволяє вибрати лише один варіант із групи взаємовиключних. Вибір одного скидає інший.

2. Checkbox (прапорець)

Дозволяє вибрати кілька незалежних опцій або увімкнути/вимкнути окремий параметр.

3. Text input (текстове поле)

Призначене для введення довільного тексту користувачем (імена, пошукові запити, email тощо). Тут введений текст відображається поруч.

4. Tabs (вкладки)

Інформація про компанію.
Перелік наданих послуг.
Телефон та адреса.
Групують контент у окремі панелі на одній сторінці; одночасно видно лише одну, що економить місце та структурує інформацію.

5. Button (кнопка)

Ініціює дію за кліком користувача: відправлення форми, відкриття вікна, виконання команди.

6. Text label (текстова мітка)

Статичний текст, що підписує елемент інтерфейсу й пояснює, що вводити. Клік по мітці активує пов'язане поле (атрибут for).

7. Link (посилання)

Документація MDN
Гіперпосилання для переходу на іншу сторінку, ресурс або фрагмент поточної сторінки.

8. Tooltip (підказка)

Наведіть курсор сюдиЦе спливаюча підказка
Короткий текст, що з'являється при наведенні курсора й дає додаткове пояснення, не займаючи місця на сторінці постійно.

9. Dropdown list (випадаючий список)

Компактно показує набір варіантів і дозволяє вибрати один; розкривається лише за потреби.
